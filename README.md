# DigitalTwin For Anything

面向铸铁件生产全流程的浏览器端数字孪生指挥中心，覆盖污染排放、设备运行、能源计量与视频监控。

## 在线体验

**https://kezhenyu-ai.github.io/DigitalTwin-For-Anything/**

在线版为只读演示，使用管理员分配的登录凭据；登录页不展示用户名和口令。静态演示中的 AI 使用看板数据的本地规则分析，不调用大模型。

## 主要功能

- **厂区数字孪生**：中频熔炼、砂处理、造型、浇注、落砂抛丸、涂装/RTO、成品库全流程三维场景。
- **排放监测**：CEMS 排口、无组织排放点、厂界 AQI、限值与达标率、实时趋势与预警。
- **设备状态**：14 台关键设备运行状态、功率、负载率、温度、振动、保养计划和设备事件。
- **运行日志**：分级筛选、搜索、CSV 导出与本地留存。
- **能源分表**：熔炼、造型浇注、清理、涂装、公用动力、环保治理六个分表，支持电/气/水/压缩空气切换。
- **视频监控**：8 路数字孪生摄像机，四分屏 / 单画面切换及通道信息。
- **AI 运营助手**：基于当前看板数据做排放风险、能耗、设备预警和值班摘要分析。
- **看板收放**：一键收起左右信息栏和底部能源条，完整查看三维厂区。

## 安装

需要 Node.js 20+：

```bash
npm install
npm run dev
```

打开：

```text
http://127.0.0.1:5173/
```

生产构建：

```bash
npm run build
npm run preview
```

## 使用说明

- 在线版和本地版均使用管理员分配的凭据登录。
- 登录页只保留必要的输入框，不展示默认用户名或默认口令。
- 左键拖拽旋转视角，右键拖拽平移，滚轮缩放。
- 单击设备打开设备详情抽屉；单击烟囱打开排放监测。
- 顶部导航打开环保、能源、视频安防等面板。
- 顶部 `看板` 收起或展开信息栏；`AI` 或 `Alt + A` 打开运营助手。
- 右上角用户头像可退出登录。

## AI 配置

本地完整版的 AI 助手需要在服务端配置 `DEEPSEEK_API_KEY`，浏览器端不会接触密钥。在线静态演示不调用大模型。

## 技术栈

Three.js / WebGL2、Vite、原生 JavaScript 与 CSS。

## 数据说明

当前排放浓度、设备状态、能耗、日志和视频画面均为演示数据，不代表真实工厂运行情况。
